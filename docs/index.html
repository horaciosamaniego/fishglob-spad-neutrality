Is relative abundance Beta distributed for neutral reasons?

The species proportional abundance distribution is Beta but not Dirichlet: a test of neutrality in fourteen bottom-trawl surveys
Horacio Samaniego1, Pablo A. Marquet2,3, Malin L. Pinsky4

1 Laboratorio de Ecoinformática, Instituto de Conservación, Biodiversidad y Territorio, Universidad Austral de Chile, Valdivia, Chile.
2 Instituto de Sistemas Complejos de Valparaíso, Valparaíso, Chile.br> 3 Facultad de Ciencias Biológicas, Pontificia Universidad Católica de Chile, Santiago 8331150, Chile; The Santa Fe Institute, 1399 Hyde Park Road, Santa Fe, NM 87501, USA.
4 Department of Ecology and Evolutionary Biology, University of California Santa Cruz, Santa Cruz, CA 95060.

Neutral theory predicts that the relative abundance of species follows a Beta distribution, and that the whole assemblage follows a Dirichlet. The Dirichlet carries a constraint the Beta alone does not: its concentration parameter is a community-level sum, so every species must share one value. It does not hold in any survey we examined.

What this repository contains

Annual biomass shares for fourteen survey units drawn from six scientific bottom-trawl programmes across four ocean basins, together with the code that fits a Beta distribution to each species, tests whether the concentration parameters are equal, and calibrates that test against bootstraps simulating autocorrelated Jacobi paths rather than an asymptotic reference.

The headline results are that the Beta is an adequate marginal description, that the shared concentration is rejected in every survey unit, and that the failure takes the form of a Taylor exponent near 2 where neutral drift requires 1 — so rare and common species fluctuate by similar proportions of their own abundance.

Reproducing the results

git clone https://github.com/horaciosamaniego/fishglob-spad-neutrality.git
cd fishglob-spad-neutrality
pip install -r requirements.txt
make all          # or: python src/run_analysis.py

The first run downloads survey files from the FishGlob repository into ~/.fishglob. A reduced smoke test, make quick, finishes in about three minutes. The full pipeline takes roughly forty. Seeds are fixed, so the likelihood ratio, the fitted parameters and the Taylor exponents reproduce exactly; bootstrap quantiles and power estimates carry the usual Monte Carlo variation.

Data

All survey data come from FishGlob v2.1.0 (Maureaud et al. 2024, CC BY 4.0), downloaded at run time rather than redistributed here. The single file shipped in data/ is the derived share matrix for the pilot region, so the analysis can be re-run without network access.

FishGlob asks that users read its disclaimer and citation policy and notify the consortium of the datasets used, so that the data providers receive credit.
