# Is relative abundance Beta distributed for neutral reasons?

Data and analysis code for *The species proportional abundance distribution is Beta but not Dirichlet: a test of neutrality in fourteen bottom-trawl surveys*.



**Site:** https://horaciosamaniego.github.io/fishglob-spad-neutrality/


---

## What this repository contains

Annual biomass shares for fourteen survey units drawn from six scientific bottom-trawl programmes across four ocean basins, and the code that fits a Beta distribution to each species' share, tests whether the concentration parameters are equal across species, and calibrates that test against parametric bootstraps simulating autocorrelated Jacobi paths.

Neutral models of community dynamics, written as diffusions on proportions rather than counts, converge on a Beta stationary distribution, and their multivariate generalisation is Dirichlet. The Dirichlet carries a constraint the Beta alone does not: its concentration parameter is a sum over the whole assemblage, so it carries no species index and must be identical for every species. That constraint is what this code tests.

The headline results are that the Beta is an adequate marginal description, that the shared concentration is rejected in every survey unit examined, and that the failure takes the form of a Taylor exponent between 1.70 and 1.99 where neutral drift requires 1 — so rare and common species fluctuate by similar proportions of their own abundance rather than the rare ones being proportionally steadier.

## Reproducing the results

```bash
git clone https://github.com/horaciosamaniego/fishglob-spad-neutrality.git
cd fishglob-spad-neutrality
pip install -r requirements.txt
make all          # or: python src/run_analysis.py
```

`make quick` runs a reduced smoke test in about three minutes; `make all` takes roughly forty, most of it in the bootstraps. The first run downloads the survey files it needs from the FishGlob repository into `~/.fishglob` (override with `FISHGLOB_CACHE`) and caches Parquet copies, so later runs start in about a second.

Seeds are fixed, so the likelihood ratio, the fitted parameters and the Taylor exponents reproduce exactly. Bootstrap quantiles and power estimates carry the usual Monte Carlo variation — a percent or two on the quantiles, several percent on the power points.

Individual stages can be run on their own, and each builds whatever it needs:

```bash
python src/run_analysis.py --stage shares    # species × year share matrix
python src/run_analysis.py --stage fits      # per-species Beta fits, Taylor slope
python src/run_analysis.py --stage boot      # the test: LR + bootstrap null
python src/run_analysis.py --stage power     # size and power curve
python src/run_analysis.py --stage subsets   # robustness checks
python src/run_analysis.py --stage gof       # marginal Beta goodness of fit
python src/run_analysis.py --stage figure    # Figure 1
```

## Layout

```
data/     derived share matrix for the pilot region
src/      analysis code
output/   result tables and console logs, regenerated by make
figures/  Figures 1 and 2 of the paper
docs/     project site (GitHub Pages)
```

### `src/nu_test.py`

The core. Builds annual biomass shares from a FishGlob survey, fits Beta distributions in mean–concentration form by profile likelihood, computes the likelihood ratio comparing free against shared concentrations, estimates each species' mean-reversion rate from its lag-1 autocorrelation, simulates Jacobi diffusion paths, and runs the parametric bootstrap.

### `src/betagof.py`

The $L^2$-type goodness-of-fit test for the Beta family of [Ebner & Liebenberg (2021)](https://doi.org/10.1002/sta4.341), with the classical EDF competitors calibrated by the same parametric bootstrap so that the four are comparable. The $O(n^2)$ double sum of the published statistic is replaced by an exact $O(n \log n)$ form built on order statistics, which is what makes bootstrapping it affordable.

### `src/fishglob.py`

FishGlob access: download, Parquet caching, subsetting by survey unit, stratum, year and taxon, and reconstruction of the haul × taxon matrix with the structural zeros reinstated.

### `src/run_analysis.py`

Driver for the pilot region. Stages cache their outputs, so entering at any stage works.

### `src/run_regions.py`, `src/profile_surveys.py`

The cross-region analysis. `profile_surveys.py` reports each survey's gear history and species coverage and selects a window; `run_regions.py` runs the test in each.

### `src/make_figure.py`, `src/make_region_figure.py`

Figures 1 and 2. Both read the result tables in `output/`, so a figure always matches the run that produced it.

## Notes on the null distribution

The asymptotic $\chi^2$ reference for the likelihood ratio is not used. Annual series are short — 16 to 46 years — and the Beta concentration is poorly determined at that length; more importantly, a species' shares are an autocorrelated Jacobi *path* rather than an i.i.d. sample, so an i.i.d. bootstrap would understate the sampling variance of the fitted concentration and over-reject the null.

The bootstrap therefore simulates the Jacobi diffusion

```
dX = a (b - X) dt + sigma sqrt(X (1 - X)) dW
```

whose stationary law is Beta with mean `b` and concentration `2a/sigma^2`, and whose autocorrelation is `exp(-a h)`. Under the null each species keeps its own fitted mean and its own mean-reversion rate, estimated from its observed lag-1 autocorrelation, while all share one concentration.

This is not a cosmetic choice. On the pilot region the correctly calibrated 5% critical value is 66.3 against 33.9 from $\chi^2_{22}$, so the asymptotic test would have been anticonservative by a factor of two. The simulator is verified against long paths to confirm it recovers target means, concentrations and autocorrelations, and the test is verified to have correct size — 4% against a nominal 5% — when simulated under the null.

## Notes on window selection

Bottom-trawl surveys change vessels and gear, and those changes produce step changes in catchability that would otherwise be read as ecological variance. Rather than rely on programme-specific knowledge for each of six survey programmes, windows are selected from the data: for each survey unit, the longest run of consecutive years sharing one dominant gear.

For the Northeast US shelf this recovers 1963–2008, ending exactly at the documented *Albatross IV* to *Henry B. Bigelow* transition, for which FishGlob does not apply calibration factors. `output/survey_profile.csv` records what was selected for every survey unit, so the choice is auditable rather than assumed.

## Notes on the FishGlob columns

Three things are worth knowing before reusing these products, all encountered here and all documented in the manuscript.

`wgt_cpua` for the NEUS survey equals `wgt` divided by a constant swept area, so it is a unit change rather than an effort standardisation. `num_cpua` is *not* `num / area_swept`, and the two count columns disagree by up to four orders of magnitude; the analysis uses biomass for this reason, as well as because the underlying models are biomass models.

About 10% of NEUS records carry `num > 0` with `wgt` and `num_cpua` exactly zero — presences recorded as absences. These are reported rather than silently squeezed, because whether a zero is structural or observational is itself a biological question; two otherwise eligible species are excluded from the pilot analysis as a result.

The Gulf of St Lawrence north file and the compiled multi-survey file both fail to parse under UTF-8, owing to non-UTF-8 bytes in verbatim taxon names.
